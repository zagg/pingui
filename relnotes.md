Ping graphique historique façon gping, en mieux et 100% Rust.

- ICMP natif v4/v6 (aucun processus ping externe)
- Fenêtre egui (--gui) + TUI ratatui + mode batch
- Courbe historique colorée, carte de trafic, histogramme, table des paquets
- min/avg/max/mdev, écart-type, jitter, p50/p90/p95/p99
- Export CSV/JSON, mode simulation (--demo)

Binaire Windows x86_64 : télécharge le zip, décompresse, lance pingui.exe.
